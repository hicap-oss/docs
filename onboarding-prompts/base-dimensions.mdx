Use this focused prompt to assess and configure applicable service-wide values, such as environment and system, using your existing tagging helper. The agent separates observed conventions from recommendations and reports unresolved values.

This prompt requires an existing Hicap client and tagging helper. If the helper is missing, use the [tagging helper prompt](/onboarding-prompts/tagging-helper) first.

The block below includes the task and its shared contract for your coding agent. Review both before use, then review the agent's changes and verification report. For the overall workflow, see [Set up Hicap with a coding agent](/concepts/implement-attribution-with-an-agent).

````text wrap title="Implementation prompt"
Review and configure this application's service attribution using its existing
Hicap helper. If the helper is missing, report that prerequisite and point to
the tagging-helper prompt; skip base-dimension implementation until it exists.
Find approved environment, service and domain conventions first;
use the platform's deployment context where configured. Do not replace existing
approved values with generic industry defaults. Show observed and recommended
values separately for all six dimensions. Put only service-wide defaults in
configuration; preserve workflow-specific roles and business features per caller.
Leave unresolved deployment settings explicit, rather than inventing fallbacks.

Before making changes, read and apply the complete versioned shared contract at
https://docs.hicap.ai/onboarding-prompts/focused-attribution-contract-v1.
If it is unavailable, stop and report the missing prerequisite; do not infer or
skip its safety and verification requirements. Record the contract revision or
content hash in the report, or state that provenance could not be verified.
````
