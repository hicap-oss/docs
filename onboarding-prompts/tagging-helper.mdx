Use this focused prompt when an existing Hicap integration needs a tagging helper or its merge behavior needs repair. The agent checks real callers, concurrency, and provider boundaries.

This prompt does not change routing. Configure a [Hicap client](/onboarding-prompts/configure-client) first.

The block below includes the task and its shared contract for your coding agent. Review both before use, then review the agent's changes and verification report. For the overall workflow, see [Set up Hicap with a coding agent](/concepts/implement-attribution-with-an-agent).

````text wrap title="Implementation prompt"
Add or repair a shared Hicap tags helper after reviewing existing tags, callers
and merge precedence. Preserve compatible extras. Attach it to existing
Hicap-bound model transports, including scripts and jobs; list deferrals explicitly. Trace
caller context through shared helpers, fallback paths, retries and queues.
Inspect the actual named roles already used by product workflows so the helper
does not serialize valid JSON while dropping the agent dimension.

Before making changes, read and apply the complete versioned shared contract at
https://docs.hicap.ai/onboarding-prompts/focused-attribution-contract-v1.
If it is unavailable, stop and report the missing prerequisite; do not infer or
skip its safety and verification requirements. Record the contract revision or
content hash in the report, or state that provenance could not be verified.
````
