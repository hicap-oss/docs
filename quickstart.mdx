The Hicap API gives you access to foundation models from OpenAI, Anthropic, Google Gemini, and more — through a single OpenAI-compatible endpoint. Use a compatible OpenAI SDK with Hicap's base URL and required auth header. Endpoint features and parameters depend on the selected model.

## 1. Get your API key

<Note>
  **Opens the Hicap Platform** — You'll create an account and generate an API key in the [Hicap Platform dashboard ↗](https://platform.hicap.ai/). Then come back here to use it.
</Note>

Keep the key on your server. Export it as an environment variable; never use a public/browser environment variable:

```bash
export HICAP_API_KEY="your_api_key_here"
```

## 2. Install an SDK and make your first request

<Tabs>
  <Tab title="JavaScript">
    ```bash
    npm install openai
    ```

    ```javascript example.mjs
    import OpenAI from "openai";

    const client = new OpenAI({
      baseURL: "https://api.hicap.ai/v1",
      apiKey: process.env.HICAP_API_KEY,
      defaultHeaders: { "api-key": process.env.HICAP_API_KEY },
    });

    const response = await client.chat.completions.create({
      model: "gpt-5",
      messages: [{ role: "user", content: "Write a one-sentence bedtime story about a unicorn." }],
    });

    console.log(response.choices[0].message.content);
    ```

    Run with `node example.mjs`.
  </Tab>
  <Tab title="Python">
    ```bash
    pip install openai
    ```

    ```python example.py
    import os
    from openai import OpenAI

    client = OpenAI(
        base_url="https://api.hicap.ai/v1",
        api_key=os.environ["HICAP_API_KEY"],
        default_headers={"api-key": os.environ["HICAP_API_KEY"]},
    )

    response = client.chat.completions.create(
        model="gpt-5",
        messages=[{"role": "user", "content": "Write a one-sentence bedtime story about a unicorn."}],
    )

    print(response.choices[0].message.content)
    ```

    Run with `python example.py`.
  </Tab>
  <Tab title="curl">
    ```bash
    curl -s https://api.hicap.ai/v1/chat/completions \
      -H "Content-Type: application/json" \
      -H "api-key: $HICAP_API_KEY" \
      -d '{
        "model": "gpt-5",
        "messages": [{"role": "user", "content": "Write a one-sentence bedtime story about a unicorn."}]
      }'
    ```
  </Tab>
</Tabs>

That's it — you just called the Hicap API. Use an exact ID from [GET /v1/models](/api-reference/models). Verify that the selected model supports your endpoint and parameters before switching it.

## Switch between models and providers

Use compatible OpenAI, Anthropic, or Gemini chat models through the same endpoint and SDK. Tools, streaming, image input, and sampling parameters can differ between models.

```python
# OpenAI
client.chat.completions.create(model="gpt-5", messages=[...])

# Anthropic Claude
client.chat.completions.create(model="claude-sonnet-4.5", messages=[...])

# Google Gemini
client.chat.completions.create(model="gemini-2.5-pro", messages=[...])

# Moonshot Kimi
client.chat.completions.create(model="kimi-k2.5", messages=[...])
```

See all available models, context windows, and pricing → [All Models](https://hicap.ai/models) or [models.json](https://hicap.ai/models.json)

## Analyze images

For compatible vision models, include an image in the chat message. Image formats and URL fetching depend on the backend; if remote URLs are not supported, use an inline image format supported by that model.

```javascript
const response = await client.chat.completions.create({
  model: "gpt-5",
  messages: [{
    role: "user",
    content: [
      { type: "text", text: "What is in this image?" },
      { type: "image_url", image_url: { url: "https://example.com/photo.jpg" } },
    ],
  }],
});

console.log(response.choices[0].message.content);
```

## Stream responses

Use server-sent events to show results as they're generated:

```javascript
const stream = await client.chat.completions.create({
  model: "gpt-5",
  messages: [{ role: "user", content: "Explain quantum computing in simple terms." }],
  stream: true,
});

for await (const chunk of stream) {
  process.stdout.write(chunk.choices[0]?.delta?.content || "");
}
```
