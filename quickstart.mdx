## 2. Create Your First Connection

<Tabs>
  <Tab title="Step-by-step">
  
  #### ¿What is a connection?

  A connection in Hicap is the link between your system and our platform. When you create a connection, you give it a name and we generate your API keys. These keys allow your system to communicate securely with Hicap.
  
  By creating a connection, you get a <strong>secure and unique way to send and receive data with Hicap</strong>. This is the foundation for testing, integrating, and eventually letting your users access the features you provide through our platform.

  #### Create Connection

  Set up your first connection by entering basic information such as a name and description.

  <div
    className="flex justify-center"
    style={{ width: '100%', height: '100%', backgroundColor: '#F8F8F8' }}

  Then, create your first Key. With this step, you can immediately start using the Starter plan in <strong>test mode</strong>. This allows you to test if your connection works, but it will not enable your users to consume tokens yet.

    #### Unlock the production environments

    To unlock production environments such as Pay as you go, Managed-Premium, or Standard, you will need to add funds to your account. [Learn how to do it here](#)

  #### Confirm your setup

  Once you have created your connection and Key, you will see a summary of your operation, including your Primary Key and Secondary Key. These keys are essential for integrating Hicap with your system.

  <strong>Use the Primary Key</strong> to establish the main connection, and keep <strong>the Secondary Key as a backup for security</strong> or recovery purposes. Enter these keys into your system according to your integration setup to start testing and using your connection with Hicap.

  Tip: Keep your keys secure and do not share them publicly.

<Tabs>
  <Tab title="Step-by-step">

  ### Install Dependencies
  Install the OpenAI SDK using pip (Requires: Python >=3.8):

  <CodeGroup>
    ```python python
    pip install openai
    ```
  </CodeGroup>

  ### Authenticating using Hicap Endpoint and API KEY
  To create a client with the OpenAI SDK using an API key, initialize the client by passing your API key to the SDK's configuration. This allows you to authenticate and interact with OpenAI's services seamlessly

  <CodeGroup>

    ```python python
    import os
    from openai import OpenAI

    client = AzureOpenAI(
      api_version="2024-12-01-preview",
      endpoint="https://cog-cline-westus3-managed-001.openai.azure.com/",
      credential=AzureKeyCredential("<API_KEY>")
    )
    ```
  </CodeGroup>

  ### Code Sample
  This sample demonstrates a basic call to the chat completion API. The call is synchronous.

  <CodeGroup>

    ```python python
    import os
    from openai import AzureOpenAI

    endpoint = "https://cog-cline-westus3-managed-001.openai.azure.com/"
    model_name = "gpt-4"
    deployment = "gpt-4-turbo"

    subscription_key = "<your-api-key>"
    api_version = "2024-12-01-preview"

    client = AzureOpenAI(
      api_version=api_version,
      azure_endpoint=endpoint,
      api_key=subscription_key,
    )

    response = client.chat.completions.create(
      messages=[
        {
          "role": "system",
          "content": "You are a helpful assistant.",
        },
        {
          "role": "user",
          "content": "I am going to Paris, what should I see?",
        }
      ],
      max_tokens=4096,
      temperature=1.0,
      top_p=1.0,
      model=deployment
    )

    print(response.choices[0].message.content)
    ```

## 4. Test Mode vs Production mode

<Tabs>

    #### What is Test Mode?

    In Test Mode (available with the Starter plan), you can create connections, generate API keys, and run test requests to verify that your integration works as expected. Test Mode is perfect for development and debugging because no real tokens are consumed by your end users.
  
    #### What is Production Mode?

    In Production Mode, your connections are live. End users can start consuming tokens through your integration, and usage will be billed according to your selected plan. To unlock Production Mode, you need to add credits or funds to your Hicap account.
  
    <Note>
      #### Fund your account to unlock Production Mode

      [Learn how to add credits to your account](#) or [See our pricing plans](#)
    </Note>
