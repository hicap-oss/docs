The Hicap API gives you access to foundation models from OpenAI, Anthropic, Google Gemini, and more — through a single OpenAI-compatible endpoint. Use any standard OpenAI SDK and start building in under 5 minutes.

## Set up with an agent

Copy this prompt into your coding agent with your application repository open. It walks through three steps: **configure the client**, **add attribution**, and **connect usage to business outcomes**.

```text wrap title="Three-step setup prompt"
Help me set up Hicap in this application. Inspect the repository first, then
work through these three steps in order:

1. Configure the client.
   Read https://docs.hicap.ai/onboarding-prompts/configure-client and help me
   set this up. Reuse the existing client where possible, keep HICAP_API_KEY
   server-side, and verify the Hicap base URL and api-key header.

2. Add attribution.
   Read https://docs.hicap.ai/onboarding-prompts/attribution and help me set
   this up. Trace real model workflows and assess agent, env, system, feature,
   operation, and domain. Verify the final outgoing tags with mocked model responses
   and report any missing or intentionally non-applicable dimensions.

3. Connect usage to business outcomes.
   Identify the business workflows this application's AI calls support.
   Propose measurable outcomes from the code and existing analytics, such as
   a resolved support case or a completed document review, and ask me to
   confirm the outcome definitions before implementing tracking.
   Reuse the application's existing analytics or event system to record
   actual outcomes and correlate them with the relevant workflow and AI
   usage. Keep sensitive data out of attribution tags. Do not treat a
   successful model response or a feature tag as proof of a business outcome.
   Define how to measure cost per completed outcome, identify missing data,
   and verify the tracking with mocked workflows. Do not invent Hicap
   outcome APIs or claim business impact without observed evidence.

Summarize what changed, what was tested, and what still requires deployment
or fresh production traffic to verify.
```

Review the maintained [client setup prompt](/onboarding-prompts/configure-client) and [attribution prompt](/onboarding-prompts/attribution). For more detail on attribution, see [Tags, Dimensions & Segments](/concepts/tags-dimensions-segments).

You'll need an API key from the [Hicap Platform dashboard ↗](https://platform.hicap.ai/). Keep it in server-side configuration; do not paste it into the prompt.

## Manual client setup

Prefer to configure the client yourself? Follow the examples below, then use steps 2 and 3 of the prompt to add attribution and outcome tracking.

### 1. Get your API key

<Note>
  **Opens the Hicap Platform** — You'll create an account and generate an API key in the [Hicap Platform dashboard ↗](https://platform.hicap.ai/). Then come back here to use it.
</Note>

Export it as an environment variable:

```bash
export HICAP_API_KEY="your_api_key_here"
```

### 2. Install an SDK and make your first request

<Tabs>
  <Tab title="JavaScript">
    ```bash
    npm install openai
    ```

    ```javascript example.mjs
    import OpenAI from "openai";

    const client = new OpenAI({
      baseURL: "https://api.hicap.ai/v1",
      apiKey: process.env.HICAP_API_KEY,
      defaultHeaders: { "api-key": process.env.HICAP_API_KEY },
    });

    const response = await client.chat.completions.create({
      model: "gpt-5",
      messages: [{ role: "user", content: "Write a one-sentence bedtime story about a unicorn." }],
    });

    console.log(response.choices[0].message.content);
    ```

    Run with `node example.mjs`.
  </Tab>
  <Tab title="Python">
    ```bash
    pip install openai
    ```

    ```python example.py
    import os
    from openai import OpenAI

    client = OpenAI(
        base_url="https://api.hicap.ai/v1",
        api_key=os.environ["HICAP_API_KEY"],
        default_headers={"api-key": os.environ["HICAP_API_KEY"]},
    )

    response = client.chat.completions.create(
        model="gpt-5",
        messages=[{"role": "user", "content": "Write a one-sentence bedtime story about a unicorn."}],
    )

    print(response.choices[0].message.content)
    ```

    Run with `python example.py`.
  </Tab>
  <Tab title="curl">
    ```bash
    curl -s https://api.hicap.ai/v1/chat/completions \
      -H "Content-Type: application/json" \
      -H "api-key: $HICAP_API_KEY" \
      -d '{
        "model": "gpt-5",
        "messages": [{"role": "user", "content": "Write a one-sentence bedtime story about a unicorn."}]
      }'
    ```
  </Tab>
</Tabs>

That's it — you just called the Hicap API. The same code works with any [supported model](https://hicap.ai/models); just change the `model` parameter.

## Switch between models and providers

One API, any model. Use OpenAI, Anthropic, or Gemini models through the same endpoint and SDK — no separate integrations needed.

```python
# OpenAI
client.chat.completions.create(model="gpt-5", messages=[...])

# Anthropic Claude
client.chat.completions.create(model="claude-sonnet-4.5", messages=[...])

# Google Gemini
client.chat.completions.create(model="gemini-2.5-pro", messages=[...])

# Moonshot Kimi
client.chat.completions.create(model="kimi-k2.5", messages=[...])
```

See all available models, context windows, and pricing → [All Models](https://hicap.ai/models) or [models.json](https://hicap.ai/models.json)

## Analyze images

Send image URLs directly to vision-capable models:

```javascript
const response = await client.chat.completions.create({
  model: "gpt-5",
  messages: [{
    role: "user",
    content: [
      { type: "text", text: "What is in this image?" },
      { type: "image_url", image_url: { url: "https://example.com/photo.jpg" } },
    ],
  }],
});

console.log(response.choices[0].message.content);
```

## Stream responses

Use server-sent events to show results as they're generated:

```javascript
const stream = await client.chat.completions.create({
  model: "gpt-5",
  messages: [{ role: "user", content: "Explain quantum computing in simple terms." }],
  stream: true,
});

for await (const chunk of stream) {
  process.stdout.write(chunk.choices[0]?.delta?.content || "");
}
```
