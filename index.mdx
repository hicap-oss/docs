## Why Hicap?

Hicap gives you secure, enterprise-ready access to top models from OpenAI, Anthropic, Google Gemini, Moonshot, Zhipu, and MiniMax — with up to 25% lower inference costs.

The **Hicap API** is fully compatible with the [OpenAI API specification](https://platform.openai.com/docs/api-reference). Point any OpenAI SDK at `https://api.hicap.ai/v1` and use any supported model — no code changes required beyond the base URL and API key.

<Info>
  **OpenAI-compatible API** — The Hicap frontend API follows the OpenAI API spec. Use the standard OpenAI SDKs (Python, Node.js, etc.) with `base_url` set to `https://api.hicap.ai/v1`. All chat completions, embeddings, images, audio, and assistants endpoints work the same way. See the [Quickstart](/quickstart) for examples.
</Info>

<Note>
  **Live model catalog** — The full list of available models, pricing, and context windows is published at [hicap.ai/models.json](https://hicap.ai/models.json) and kept up to date as new models are added. The table below reflects the current catalog.
</Note>
