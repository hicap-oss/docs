## Overview

The **Hicap API** is fully compatible with the [OpenAI API specification](https://platform.openai.com/docs/api-reference). All endpoints follow the same request/response format as the OpenAI API — you can use any standard OpenAI SDK by simply changing the base URL to `https://api.hicap.ai/v1`.

<Info>
  **Base URL:** `https://api.hicap.ai/v1`

  All endpoints documented in the [OpenAI API reference](https://platform.openai.com/docs/api-reference) are supported, including Chat Completions, Embeddings, Images, Audio, and Assistants.
</Info>

## Authentication

All Hicap API endpoints are authenticated using your Hicap API key. Include it in either the `Authorization` header or the `api-key` header:

```bash
# Using Authorization header
curl https://api.hicap.ai/v1/chat/completions \
  -H "Authorization: Bearer YOUR-HICAP-API-KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-5", "messages": [{"role": "user", "content": "Hello"}]}'

# Using api-key header
curl https://api.hicap.ai/v1/chat/completions \
  -H "api-key: YOUR-HICAP-API-KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-5", "messages": [{"role": "user", "content": "Hello"}]}'
```

## Supported Endpoints

| Endpoint | Description |
| --- | --- |
| `POST /v1/chat/completions` | Chat completions (streaming supported) |
| `POST /v1/embeddings` | Text embeddings |
| `POST /v1/images/generations` | Image generation (DALL·E) |
| `POST /v1/audio/transcriptions` | Audio transcription (Whisper) |
| `POST /v1/audio/translations` | Audio translation |
| `POST /v1/audio/speech` | Text-to-speech |
| Assistants API | Full Assistants, Threads, Messages, Runs, and Vector Stores |

## Models

Pass any [supported model ID](https://hicap.ai/models.json) in the `model` field. The Hicap API supports 42 models across OpenAI, Anthropic, Google Gemini, Moonshot, Zhipu, and MiniMax — all accessible through the same OpenAI-compatible interface.

See the [Model Comparison](/providers/table-comparison) for a full list of available models, capabilities, and context windows.
